# Simple Calculator

## Description
This is a simple calculator program that allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. The program is designed to be user-friendly and easy to use, making it ideal for beginners who want to practice programming concepts.

## Features
- Perform addition, subtraction, multiplication, and division
- Basic input validation to ensure correct numeric input
- Command-line interface (CLI) for easy interaction
- Clear and concise results displayed after each calculation

## Tools & Technologies
- Python
- Markdown
- GitHub

## How to Use
1. Open a terminal or command prompt on your computer.  
2. Navigate to the folder where the program is saved.  
3. Run the program by:
    enter the first number.
    Choose the operation you want to perform (+, -, *, /).
    Enter the second number.
    The program will display the result.
    Repeat the process to perform more calculations or close the program to exit.
   
## Purpose of the Program
The purpose of this project is to help beginners practice programming fundamentals, including handling user input, performing arithmetic operations, and implementing simple logic. It also serves as an introduction to writing clean, functional code and creating interactive command-line applications.
